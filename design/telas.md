# 📂 Telas - Projeto Hermes

Esta pasta contém todas as telas desenvolvidas para o sistema **Hermes: Vida Escolar em Tempo Real**.

Os protótipos representam os principais fluxos da aplicação, contemplando os diferentes perfis de usuários do sistema, como responsáveis, professores e funcionários administrativos.

Aqui estão incluídas interfaces relacionadas a:

- Dashboard
- Agenda Escolar
- Desempenho Acadêmico
- Notificações
- Calendário Letivo
- Agendamentos
- Gerenciamento de Usuários
- Gerenciamento de Alunos
- Envio de Avisos
- Lançamento de Notas

As telas foram desenvolvidas seguindo princípios de UX/UI, arquitetura de informação e design centrado no usuário, buscando garantir uma navegação simples, intuitiva e organizada.
